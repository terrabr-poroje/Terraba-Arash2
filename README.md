# ترابار | TERRABAR

ترابار یک بازار آنلاین تخصصی برای معاملات عمده، خرده، ویژه و ویژه حرفه‌ای میوه و تره‌بار است که ارتباط مستقیم تأمین‌کنندگان، بارفروشان (حجره‌داران) و خریداران را در سراسر کشور برقرار می‌کند.

## معماری فنی و زیرساخت بومی (بدون Supabase)

این پروژه به‌صورت کامل بر پایه زیرساخت زیر پیاده‌سازی شده است:

- **فرانت‌اند و مسیریابی:** React 19 + TanStack Router + Tailwind CSS
- **پایگاه داده:** **Cloudflare D1** در محیط تولید و **SQLite محلی (`.d1-local.sqlite`)** در محیط توسعه (`src/lib/d1-database.ts`)
- **لایه API واحد:** تمام مسیرهای `/api/*` در `src/lib/api-router.ts` متمرکز شده و در توسعه توسط `vite.config.ts` و در تولید توسط `src/server.ts` سرویس‌دهی می‌شوند.
- **سرویس پیامک:** **sms.ir** برای کد یک‌بارمصرف ورود/تغییر رمز و پیامک‌های رویدادمحور سفارش و تسویه (`src/lib/sms-service.ts`)
- **سرویس ایمیل:** **Resend** برای کد تأیید ایمیلی و اطلاع‌رسانی (`src/lib/email-service.ts`)
- **فضای ذخیره‌سازی تصاویر:** **ParsPack S3** همراه با بهینه‌سازی خودکار تصاویر به فرمت WebP (`src/lib/parspack-storage.ts`)

## الزامات و قابلیت‌های اصلی

- رابط کاربری کاملاً فارسی و راست‌چین (RTL)، واکنش‌گرا برای موبایل و دسکتاپ همراه با حالت روز و شب.
- ثبت‌نام و ورود با شماره موبایل (OTP پیامکی) یا ایمیل (OTP / رمز عبور)، جلوگیری از ثبت‌نام تکراری و تأیید نقش‌های حرفه‌ای توسط مدیریت.
- اعلام بار معمولی (درون‌شهری) و ویژه حرفه‌ای (سراسری/بین‌شهری) با تاریخ شمسی، زمان پاسخگویی، قیمت‌گذاری پلکانی و مدیریت کامل تصاویر، ویرایش در فرم اصلی، غیرفعال‌سازی و حذف.
- صفحه مستقل «خرید ویژه حرفه‌ای» (`/professional-purchase`) با تفکیک کامل از بازار عادی و کنترل دسترسی سرور و کلاینت.
- سبد خرید با ماندگاری ۶ ساعته در پایگاه داده، ثبت سفارش با شماره فاکتور یکتا و جلوگیری از سفارش تکراری، کسر موجودی و چرخه ارسال و تحویل.
- سیستم مالی با محاسبه خودکار کمیسیون ۵ درصدی، ثبت و تأیید شماره شبا، درخواست تسویه حساب و پنل مدیریت پرداخت‌ها.
- پنل مدیریت جامع (`/admin`) شامل تأیید عضویت‌ها، مدیریت و ویرایش اعضا و بارها، مدیریت شهرهای همجوار و مدیران شهری، گزارش پیامک‌ها و لاگ عملیات (Audit Logs) و پشتیبان‌گیری کامل SQLite / SQL / JSON.

## اجرای محلی

```sh
npm install
npm run dev
```

متغیرهای محیطی مورد نیاز در فایل `.env.example` مستند شده‌اند (بدون نگهداری کلید حساس در مخزن کد).

## آزمون و ساخت

```sh
npm test
npm run lint
npm run build
```
